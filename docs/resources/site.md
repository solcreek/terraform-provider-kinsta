# kinsta_site (Resource)

Manages a WordPress site on Kinsta, created with a live environment.

## Example Usage

```terraform
# List region codes with the kinsta_regions data source.
resource "kinsta_site" "blog" {
  display_name   = "Blog"
  region         = "us-ashburn-1"
  admin_email    = "admin@example.com"
  admin_user     = "admin"
  admin_password = var.wordpress_admin_password
  site_title     = "My Blog"

  # Deleting a site cannot be undone. Set this to false and apply before
  # destroying the site.
  deletion_protection = true
}

# An empty site without WordPress, for content deployed by other means.
resource "kinsta_site" "headless" {
  display_name = "Headless"
  region       = "eu-frankfurt-1"
  install_mode = "plain"
}
```

## Creation-only arguments

`install_mode`, `admin_email`, `admin_user`, `admin_password`, `site_title`, `wp_language`,
`is_multisite`, `is_subdomain_multisite`, `woocommerce` and `wordpressseo` are sent only when
the resource is created. Kinsta does not return them, so they are not compared with the live
installation: changing one later updates the value in state (with a warning) and changes
nothing in WordPress, and an imported resource does not need them at all.

`admin_password` is stored in state (marked sensitive). Change the password in WordPress
after creation if your state is shared.

## Deleting

`deletion_protection` defaults to `true`. With it set, destroying the resource — or a change
that would replace it — fails before anything is deleted. To delete on purpose, back the
site up, set `deletion_protection = false`, apply, and then destroy.

## Schema

### Required

- `display_name` (String) Name shown in MyKinsta. Kinsta has no API to rename a site, so changing it replaces the site — which `deletion_protection` blocks by default.

### Optional

- `admin_email` (String) WordPress admin email. Required for `install_mode = "new"`. Only used when the site is created; see *Creation-only arguments*.
- `admin_password` (String, Sensitive) WordPress admin password. Required for `install_mode = "new"`. Stored in state (marked sensitive); change it in WordPress afterwards if state is shared. Only used when the site is created; see *Creation-only arguments*.
- `admin_user` (String) WordPress admin username. Required for `install_mode = "new"`. Only used when the site is created; see *Creation-only arguments*.
- `deletion_protection` (Boolean) Refuse to delete the site. Defaults to `true`: deleting a site removes every environment, its database and its files, and Kinsta has no undo. Set it to `false` and apply before destroying the site.
- `install_mode` (String) `new` (default) installs WordPress with the admin user below. `plain` creates an empty site without WordPress, for content deployed by other means; the admin and WordPress arguments are then ignored. Only used when the site is created; see *Creation-only arguments*.
- `is_multisite` (Boolean) Install WordPress Multisite. Only used when the site is created; see *Creation-only arguments*.
- `is_subdomain_multisite` (Boolean) Use subdomains rather than subdirectories for Multisite. Only used when the site is created; see *Creation-only arguments*.
- `region` (String) Data center region, e.g. `us-ashburn-1`; list them with the `kinsta_regions` data source. Required to create a site. Kinsta does not report it back, so it is creation-only.
- `site_title` (String) WordPress site title. Required for `install_mode = "new"`. Only used when the site is created; see *Creation-only arguments*.
- `woocommerce` (Boolean) Install WooCommerce. Only used when the site is created; see *Creation-only arguments*.
- `wordpressseo` (Boolean) Install Yoast SEO. Only used when the site is created; see *Creation-only arguments*.
- `wp_language` (String) WordPress locale, e.g. `en_US` (the default when unset). Only used when the site is created; see *Creation-only arguments*.

### Read-Only

- `company_id` (String) Company the site belongs to.
- `environments` (Attributes List) The site's environments. (see [below for nested schema](#nestedatt--environments))
- `id` (String) Site ID.
- `live_environment_id` (String) ID of the site's live environment.
- `name` (String) Site name Kinsta derives from the display name (used in hostnames such as `<name>.kinsta.cloud`).
- `primary_domain` (String) Primary domain of the live environment.
- `status` (String) Site status, e.g. `live`.
